# 🔴 WAR-OPS — Iran–Israel–US Conflict Monitor

**Live Dashboard:** [war-dashboard.github.io](https://war-dashboard.github.io)

Real-time conflict intelligence dashboard tracking the 2026 Iran–Israel–US war (Operation Epic Fury), initiated February 28, 2026.

---

## Features

- **Live ticker** — scrolling breaking news headlines
- **Casualty tracker** — Iran / Israel / US / Lebanon / Gulf states
- **Interactive SVG map** — Middle East theater with attack vectors
- **Strike statistics** — CENTCOM-sourced data (6,000+ targets, 90+ Iranian vessels)
- **Threat matrix** — per-actor threat level assessment
- **Economic impact** — oil prices, Hormuz status, IEA response
- **Conflict timeline** — Day-by-day events from Feb 28 to present
- **Key actors** — leadership profiles & current status
- **OSINT/Cyber feed** — intelligence notes and open-source findings
- **Auto-updating day counter** — based on Feb 28, 2026 start date
- **Animated data counters** — on page load
